# Hermes Personal Assistant Workflow

Hermes is useful for personal assistant tasks where a cleaner writing style, narrower channel context, or separate operator persona improves the result.

Example categories:

- classified listing drafts
- marketplace copy review
- lightweight everyday planning
- focused rewrite and posting workflows

The public lesson is not the private content of a listing. The reusable pattern is a constrained channel, clear task boundary, draft-review-publish flow, and no credential exposure.
