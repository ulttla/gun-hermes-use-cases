# Public-Safe Evidence

Public repositories should demonstrate the operating pattern without exposing the private workstation.

## Exclude

- credentials, tokens, cookies, saved passwords
- private channel IDs and raw Discord logs
- internal hostnames and sensitive paths
- private browser profile data
- personal financial or account data

## Rewrite pattern

Raw private evidence becomes a public-safe explanation: problem, action, result, guardrails, and reusable lesson.
