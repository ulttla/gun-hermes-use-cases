# Shared Brain Collaboration

OpenClaw and Hermes are most useful when they do not become isolated memory islands. The operating model uses gun-wiki as a practical single-brain knowledge base.

## Pattern

- OpenClaw handles broad orchestration, development windows, and portfolio work.
- Hermes handles recovery review, focused research, personal assistant workflows, and Hermes-specific maintenance.
- gun-wiki keeps durable project decisions, reusable notes, and cross-operator context.

## Why it matters

The value is not just having two bots. The value is having two operators that can review each other while sharing durable context under human approval gates.
