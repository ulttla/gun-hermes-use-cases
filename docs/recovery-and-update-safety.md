# Recovery and Update Safety

Hermes is useful as an independent reviewer for recovery and update work.

## Pre-action

- confirm scope
- capture backup evidence
- prepare rollback plan
- create continuation checkpoint
- get explicit approval for risky actions

## During action

- keep changes isolated where possible
- record smoke-test evidence
- avoid printing credentials or secrets
- delay restarts until necessary and approved

## Post-action

- review evidence from the secondary lane
- document caveats
- publish only sanitized summaries
