# Hermes Positioning

Hermes is a secondary operator lane in a supervised AI workstation. It began as an audit and recovery companion for OpenClaw and is gradually taking on tasks where a separate operator style performs better.

## What Hermes is

- a bounded audit and recovery console
- a focused personal assistant lane for selected everyday workflows
- a research lane for reusable investigation summaries
- a Hermes self-maintenance lane for improving Hermes itself

## What Hermes is not

- an autonomous failover agent
- a credential handler
- an unattended publisher
- a replacement for OpenClaw

## Recruiter signal

This pattern demonstrates operational maturity: separation of duties, independent review, human-gated risky changes, and evidence-backed recovery workflows.
