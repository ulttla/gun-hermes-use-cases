# gun-wiki Shared Brain

gun-wiki is the durable knowledge layer shared by OpenClaw and Hermes. It keeps project decisions, recovery notes, and reusable operating context in one place.

## Pattern

1. capture private work safely
2. summarize durable decisions
3. promote reusable knowledge into wiki notes
4. let each operator retrieve the same source-backed context
5. publish only sanitized public patterns

## Benefit

The system avoids duplicated knowledge drift. OpenClaw and Hermes can support each other because they can refer back to the same durable source of truth.
