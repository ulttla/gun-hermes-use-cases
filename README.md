# Gun Hermes Use Cases

Public-safe case studies showing how I use Hermes as a complementary AI operator alongside OpenClaw.

Hermes started as a backup audit and recovery lane for OpenClaw. It is now also used for tasks where a separate operator style is useful: personal assistant workflows, focused research, recovery review, and Hermes self-maintenance. The common foundation is a shared wiki-first hybrid `gun-wiki` knowledge base so both operators can work from the same durable context without becoming unchecked autonomous agents.

## What this repo is

- A recruiter-friendly portfolio of real AI-operations use cases.
- A sanitized record of where Hermes performs well.
- A companion to [`gun-openclaw-use-cases`](https://github.com/ulttla/gun-openclaw-use-cases), not a replacement.

## Current use-case tracks

1. **Secondary operator lane** — audit, rollback review, and recovery support when OpenClaw needs external review.
2. **Hermes self-maintenance lane** — Hermes configuration, behavior tuning, and runtime hardening.
3. **Personal assistant lane** — practical day-to-day tasks such as cleaner classified listing workflows.
4. **Research lane** — focused web and topic research with reusable summaries.
5. **Single-brain collaboration** — OpenClaw and Hermes sharing durable context through wiki-first gun-wiki digestion.
6. **Durable task orchestration** — SQLite-backed Kanban state for owned work, restart recovery, and audit trails.
7. **Evidence-backed goals** — persistent goals with explicit outcomes, verification, boundaries, and stop conditions.
8. **Scheduled operations** — supervised briefs and audit jobs with delivery evidence and human approval gates.
